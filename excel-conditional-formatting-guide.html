Conditional Formatting — 3 Real Projects

Excel mein rules bana kar cells ko apne aap highlight karna seekhiye — Highlight Cell Rules aur Text Contains ka use karke. Har project mein sample data, exact steps, aur final result diya gaya hai — bas dekhiye aur apne Excel mein waise hi kariye.

Conditional Formatting kya hota hai?
Ye Excel ka ek feature hai jisse aap kisi cell ki value ke basis par uska color, font ya style automatically change kar sakte ho — bina manually kuch select kiye. Jaise agar marks 33 se kam hain to cell red ho jaye, ya "Absent" likha ho to cell red highlight ho jaye. Neeche 3 projects hain — ek-ek karke follow kijiye.
Project 1

Student Marks Highlighter

Marks ke basis par Fail aur Top Scorer students ko automatically highlight karna.

Step 1 — Ye data apni Excel sheet mein type karein

NameSubjectMarks (out of 100)
RahulMaths28
PriyaMaths95
AmanMaths67
SnehaMaths19
VikasMaths91

Step 2 — Rules apply karne ke steps

  1. Column C ki saari Marks cells select karein (jaise C2:C6).
  2. Top par jaayein: Home tab → Conditional Formatting → Highlight Cells Rules → Less Than
  3. Value box mein 33 likhein, aur format dropdown se "Light Red Fill with Dark Red Text" choose karein → OK.
  4. Marks cells dobara select karein, fir se: Home → Conditional Formatting → Highlight Cells Rules → Greater Than
  5. Value box mein 90 likhein, format dropdown se "Green Fill with Dark Green Text" choose karein → OK.
Marks < 33 → Fail (Red) Marks > 90 → Top Scorer (Green)
Note: Dono rules alag-alag apply hote hain, isliye ek cell sirf ek hi condition follow karegi jo usko match karti ho.
Project 2

Attendance Status Tracker

Text ke basis par Present/Absent status ko automatically color karna — Text that Contains rule use karke.

Step 1 — Ye data apni Excel sheet mein type karein

Student NameStatus
RahulPresent
PriyaAbsent
AmanPresent
SnehaAbsent
VikasPresent

Step 2 — Rules apply karne ke steps

  1. Column B ki saari Status cells select karein (jaise B2:B6).
  2. Home tab → Conditional Formatting → Highlight Cells Rules → Text that Contains
  3. Box mein Present type karein, format se "Green Fill with Dark Green Text" select karein → OK.
  4. Status cells dobara select karein, fir se: Home → Conditional Formatting → Highlight Cells Rules → Text that Contains
  5. Box mein Absent type karein, format se "Light Red Fill with Dark Red Text" select karein → OK.
Contains "Present" → Green Contains "Absent" → Red
Tip: "Text that Contains" rule sirf specific word dhundhti hai — isliye agar aap "Leave" jaisa ek aur status add karna chahein to ek aur rule same tarike se bana sakte hain.
Project 3

Fee Payment Tracker

Fee status ke basis par Pending aur Overdue payments ko highlight karna, saath mein Overdue dates ko bhi.

Step 1 — Ye data apni Excel sheet mein type karein

Student NameFee StatusDue Date
RahulPaid02-Sep-2026
PriyaPending18-Sep-2026
AmanOverdue05-Sep-2026
SnehaPaid10-Sep-2026
VikasPending25-Sep-2026

Step 2 — "Pending" aur "Overdue" text highlight karna

  1. Column B (Fee Status) select karein.
  2. Home → Conditional Formatting → Highlight Cells Rules → Text that Contains
  3. Box mein Pending type karein → format "Yellow Fill with Dark Yellow Text" → OK.
  4. Column B dobara select karein → same steps repeat karein, box mein Overdue type karein → format "Light Red Fill with Dark Red Text" → OK.
  5. Bold text ke liye: rule dobara open karein (Conditional Formatting → Manage Rules) → Format button → Font tab → Bold select karein → OK.

Step 3 — Due Date ko "Dates Occurring" rule se highlight karna

  1. Column C (Due Date) select karein.
  2. Home → Conditional Formatting → Highlight Cells Rules → A Date Occurring...
  3. Dropdown se "In the Last 7 Days" (ya "Yesterday") select karein — ye already-due dates ko highlight karega.
  4. Format "Light Red Fill with Dark Red Text" select karein → OK.
Contains "Pending" → Yellow Contains "Overdue" → Red + Bold
Note: "A Date Occurring" rule tabhi kaam karegi jab Due Date column mein values actual Excel date format mein ho (text ki tarah type na ki ho).
Practice karne ka tareeka: Teeno projects khud apni Excel sheet mein banaiye, ek-ek row change karke dekhiye ki color kaise apne aap badalta hai. Agar rule kaam na kare, to Conditional Formatting → Manage Rules mein jaakar check karein ki cell range aur condition sahi hai ya nahi.
